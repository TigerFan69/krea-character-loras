## Installation and usage

These are adapters, not complete base models. Obtain a compatible Krea 2 base model and required components separately under their own terms. For ComfyUI, place the `.safetensors` adapter in `ComfyUI/models/loras/`, refresh, and select it in a compatible workflow. Follow the linked card for the exact trigger and version-specific guidance.

Lisa’s creator reports good results at strength 1.0. Erika was previously tested up to 1.5 in the creator’s own setup; this is not a universal recommendation, and the current v4.1 guidance should be checked separately. Annabel v3 does not require a trigger; earlier version triggers should not be applied automatically.
