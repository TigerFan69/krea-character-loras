## Installation and usage

These are adapters, not standalone base models. Read the included license, creator terms and model-specific README. Obtain compatible Krea 2 components separately under their terms. For ComfyUI, put the original .safetensors file in ComfyUI/models/loras/, refresh and select it in a compatible Krea 2 workflow. Use each version’s exact trigger.

Annabel v3 requires no trigger. Lisa works well at 1.0 in the creator’s setup. Erika v4.1 reports 1.25/1.3 in its current workflow; older tests up to 1.5 are not a universal recommendation. Compare fixed seeds and prompts for identity, skin, hair, anatomy and background artifacts.
